一、JS 与浏览器（1–14）

1★ 事件循环讲一下，微任务和宏任务谁先？

同步代码执行完，先清空微任务队列，再取下一个宏任务；每个宏任务结束后再清一次微任务，然后才可能渲染。宏任务：setTimeout、setInterval、I/O、事件回调；微任务：Promise.then、queueMicrotask、MutationObserver。所以 setTimeout(fn, 0) 一定排在 Promise.resolve().then() 后面。

2闭包是什么？会有什么问题？

函数引用了外层作用域的变量，外层执行完这些变量也不释放，就是闭包。防抖节流、缓存、模块私有变量都靠它。问题是引用大了不释放会占内存，比如闭包里留了个已经移除的 DOM 节点，就泄漏了。

3原型链说一下。

实例找属性：自己 → 构造函数 prototype → 它自己的 prototype …… 一直到 Object.prototype，再往上 null。__proto__ 指向原型对象，prototype 是函数才有的属性，两者别混。instanceof 就是沿着原型链找。

4this 的指向规则？

默认指向全局（严格模式 undefined）；obj.fn() 指向 obj；call/apply/bind 显式指定；new 指向新对象；箭头函数没有自己的 this，取定义时外层的。优先级大概：new > 显式绑定 > 隐式绑定 > 默认。

5Promise 和 async/await，错误怎么处理？

Promise 三种状态不可逆，.then 返回新 Promise，.catch 接错误，.finally 收尾。async 函数返回 Promise，await 等结果，错误用 try/catch 包。并发用 Promise.all（一个失败全失败）、要容错用 allSettled。坑是在 forEach 里写 await 不会等，得用 for...of 或者 Promise.all(map)。

6深拷贝浅拷贝，你一般怎么写？

浅拷贝用展开或者 Object.assign，嵌套对象还是共用引用。深拷贝现在直接 structuredClone，能处理 Date、Map、循环引用；JSON.parse(JSON.stringify()) 会丢函数、undefined、Date 变字符串，只在纯数据时用。手写递归要处理循环引用，用 WeakMap 记一下。

7防抖和节流，项目里用在哪？

防抖是等停止触发再执行，用在搜索框输入、窗口 resize 后重算表格高度；节流是固定间隔执行一次，用在滚动监听更新答题卡高亮、按钮防连点。手写就是定时器加时间戳，也可以用 lodash。我在育龄平台的表格自适应和职证宝的答题卡滚动里都用过。

8数组常用方法，哪些会改原数组？

push/pop/shift/unshift/splice/sort/reverse 改原数组；map/filter/slice/concat 返回新的。sort 默认按字符串排，数字要传比较函数。大数组别连着写好几个 map 再 filter，合并成一次遍历更快。

9ES6+ 你常用的有哪些？

解构、展开、模板字符串、箭头函数、let/const（暂时性死区）、可选链 ?.、空值合并 ??、includes、Object.entries、模块化 import/export。用得最多的是解构和可选链，接口返回层级深，不写可选链会报错。

10内存泄漏你遇到过吗？怎么排查？

常见几种：定时器没清、事件监听没解绑、闭包引用了大对象、全局变量越挂越多。排查用 DevTools 的 Memory 拍堆快照，对比前后看哪类对象一直涨；也能用 Performance 录一段看内存曲线。项目里我踩过 addEventListener 没在卸载时移除。

11浏览器渲染流程，重排和重绘有什么区别？

HTML 解析成 DOM，CSS 解析成 CSSOM，合成渲染树，布局（算位置尺寸）、绘制（画像素）、合成。改宽高、位置、字体会触发重排，代价大；改颜色、背景只重绘；改 transform 和 opacity 只走合成，最省。所以动画优先用 transform。

12跨域怎么解决？你在项目里怎么配的？

同源策略限制的是协议+域名+端口。开发环境走代理：vue-cli 在 vue.config.js 配 devServer.proxy，Vite 在 server.proxy 配，配合 rewrite 去前缀；生产是 Nginx 反代或者后端加 CORS 头。另外 JSONP 是历史方案，postMessage 用于 iframe 通信。

13强缓存和协商缓存。

强缓存看 Cache-Control/Expires，命中不发请求；协商缓存带 If-None-Match/If-Modified-Since 问服务端，没变回 304。发版最怕 index.html 被强缓存，所以它一般设 no-cache，带 hash 的静态资源设长缓存。

14前端要关注哪些 HTTP 状态码？

200 成功、201 创建、204 无内容；301/302 重定向；304 走缓存；400 参数错、401 没登录、403 没权限、404 不存在、409 冲突、429 请求过多；500 服务端错、502 网关错、504 超时。前端要按状态码分流处理，401 跳登录、403 提示权限，别一律弹"网络错误"。

二、CSS（15–21）

15盒模型，box-sizing 有什么作用？

默认 content-box，width 只管内容，padding 和 border 往上加；border-box 的 width 含 padding 和 border。项目里一般全局设 border-box，算布局不会算错。

16BFC 是什么？能解决什么问题？

块级格式化上下文，一块独立的渲染区域。触发条件：overflow 非 visible、float、position: absolute/fixed、display: flow-root、flex/grid 的子项。作用：包住浮动（清浮动）、防止 margin 上下合并、防止被浮动元素环绕。

17几种居中方式？

flex：justify-content: center + align-items: center；grid：place-items: center；绝对定位 + transform: translate(-50%, -50%)；定宽块用 margin: 0 auto。行内元素用 line-height + text-align。看场景选，flex 最通用。

18flex 里 flex: 1 代表什么？

flex: 1 等于 flex-grow: 1; flex-shrink: 1; flex-basis: 0%。所以子项按比例分剩余空间，内容多也不会撑开（basis 是 0）。两栏布局常写 flex: 1 给主内容、固定宽度给侧栏。

19z-index 为什么有时候不生效？

z-index 只对定位元素（非 static）或者 flex/grid 子项生效。另外层叠上下文是分层的，父元素形成新的上下文（transform、opacity < 1、filter、position: fixed），子元素再大的 z-index 也跳不出父级那一层。

20移动端适配你怎么做的？

viewport meta 设 width=device-width, initial-scale=1；尺寸用 rem（根字号按屏宽算）或者 vw；字号用 clamp() 控制范围；刘海屏用 env(safe-area-inset-bottom) 留安全区。瀚维那两个 H5（webapp、爱维星云）基本都是 rem 铺的，productnav 那套大屏也是全站 rem。

211px 边框在手机上为什么变粗？怎么处理？

高 DPR 屏上 CSS 的 1px 会被放大成 2 个或 3 个物理像素。常见做法：伪元素 + transform: scaleY(0.5)、box-shadow: 0 0 0 0.5px，或者直接写 0.5px（部分机型支持）。我一般用伪元素那套，兼容性好。

三、Vue（22–42）

22★ Vue3 响应式和 Vue2 有什么区别？

Vue2 用 Object.defineProperty 递归劫持属性，毛病是新增/删除属性、改数组下标监听不到，要 $set。Vue3 用 Proxy 代理整个对象，这些都能拦到；而且访问到才递归，初始化更快。腾达那套 Vue2 就踩过数组赋值不更新，创联的 Vue3 没这问题。

23ref 和 reactive 怎么选？ref 为什么要 .value？

基本类型用 ref，它包一层对象，模板自动解包、JS 里要 .value。对象我一般也用 ref，整体替换不丢响应式；reactive 适合确定不替换的对象，但解构会丢响应式，得配 toRefs。

24computed、watch、watchEffect 分别什么时候用？

computed 派生状态、有缓存，适合过滤列表这种；watch 做副作用，能拿新旧值，适合发请求、写缓存；watchEffect 自动收集依赖、立即执行，适合简单副作用。要监听多个源用 watch([a,b])，深度监听对象加 deep，但要注意性能。

25组合式 API 的生命周期怎么对应？为什么没有 created？

setup 在 beforeCreate/created 之前执行，这两步的逻辑直接写在 setup 里就行。对应：onMounted、onUpdated、onUnmounted、onBeforeUnmount；被 keep-alive 包着用 onActivated/onDeactivated。

26组件通信方式有哪些？

父子 props/emit，v-model，跨层级 provide/inject，全局 Pinia/Vuex，ref 拿实例，插槽传内容，$attrs 透传。provide/inject 我用在表单：外层 provide 表单模型和校验方法，字段组件 inject，不用一层层传。

27v-model 的原理？自定义组件怎么支持？

本质是语法糖。Vue2 是 :value + @input；Vue3 是 :modelValue + @update:modelValue。自定义组件要声明 props 并 emit 事件。Vue3 支持多个 v-model（v-model:title），组件里对不同的 prop 分别 emit。

28插槽和作用域插槽用在什么地方？

普通插槽传结构，作用域插槽把子组件内部数据暴露给父级。表格封装最典型：列的自定义渲染用作用域插槽，父组件拿到 row、index 自己决定显示什么。配置化表格里，"八成能用配置，剩下两成走插槽"就是靠它。

29keep-alive 用过吗？

列表页进详情再返回要保留筛选和滚动位置，就把列表页包进去，用 include 指定组件名，onActivated 里刷新数据但不动筛选条件。坑是组件名对不上 include 不生效，缓存不释放会吃内存。

30nextTick 是干嘛的？

Vue 的 DOM 更新是异步批量的，同一轮改多次只渲染一次。想在 DOM 更新完拿最新节点用 nextTick，底层是 Promise。比如弹窗打开后让输入框聚焦。

31虚拟 DOM 和 diff 了解多少？

虚拟 DOM 是 JS 对象描述真实 DOM，diff 找出最小改动再批量更新。Vue2 是双端比较；Vue3 加了静态提升、patchFlag（只比对动态部分）、最长递增子序列减少移动。原理我清楚，具体源码没逐行读过。

32key 有什么用？为什么不用 index？

key 帮 diff 判断节点是不是同一个，复用 DOM、减少重建。用 index 在列表插入/删除时会错位，导致状态错乱（比如输入框内容串行）。列表项有唯一 id 就用 id。

33v-if 和 v-show 怎么选？

v-if 不渲染、切换有创建销毁成本；v-show 只切 display，初次渲染成本高、切换便宜。频繁切换用 v-show，条件很少变用 v-if。权限按钮我用指令，不是这俩。

34路由 hash 和 history 的区别？

hash 带 #，不参与请求，刷新不会 404，但地址难看；history 好看，需要服务端把 404 指回 index.html（Nginx try_files）。我们项目基本用 history，部署时配好回退。

35★ 动态路由和权限怎么做的？

登录后后端返回菜单树和权限码，前端按菜单树生成路由，addRoute 挂上去；守卫 beforeEach 判断 token 和权限，没权限跳 403。退出登录要重置路由，不然换账号会残留上一个账号的菜单——这个坑我踩过。

36v-permission 指令怎么实现的？为什么不用 v-if？

mounted 里读权限码和当前用户权限集合比对，没有就 parentNode.removeChild；updated 再判一次。用指令是因为一次封装到处用，比每个按钮写 v-if 干净；缺点是逻辑藏起来，得写文档。

37★ Pinia 和 Vuex 的差别？

腾达老项目是 Vuex，state/mutations/actions 三段式，改状态必须走 mutation；创联是 Pinia，没有 mutation，action 直接改 state，TS 推导好，模块扁平不用 namespace。我更喜欢 Pinia，但维护老项目得按 Vuex 来。

38mixin 和组合式函数，后来为什么不用 mixin 了？

mixin 是隐式合并，this 上的东西从哪来不清楚，多个 mixin 同名会覆盖，改一个影响所有引用页面。组合式函数是显式引入，来源清楚、能传参、能返回多个值。我在腾达用了不少 mixin（表格/表单/设备），当时省事，后来维护确实难受。

39二次封装 el-table / el-form 的思路？要注意什么？

表格：接收 columns 配置（字段、标题、宽度、格式化），内部统一处理分页、排序、空态、loading，复杂列走作用域插槽。表单：fields 配置（类型、校验规则、联动），布局统一。要注意透传 $attrs 和 v-model，不然外面想加个属性加不上；还要留插槽口子，不然复杂页面只能绕开。

40TS 在 Vue 项目里怎么用？

接口返回定义类型（请求/响应 model）、defineProps 用泛型、字典和枚举集中放、Axios 请求函数加泛型。创联项目 src 下 300 多个 ts 文件，基本全覆盖。我没写太花的类型体操，infer 那种用得少。

41组件库按需引入和主题定制的做法？

按需用 unplugin-element-plus + unplugin-vue-components 自动引入，不用手写一堆 import；主题覆盖 CSS 变量或者改 Sass 变量，配合 vite-plugin-compression 开 gzip。别整包引入，几百 K 上去首屏就废了。

42表单校验你一般怎么做？

规则放 rules，提交前 validate()，异步校验（如用户名重复）用 callback 或返回 Promise；联动校验（选了 A 才必填 B）用 watch 或动态改 rules；错误提示统一位置。考务那种表单字段多，我按模块拆成子表单，各自校验再汇总。

四、工程化（43–51）

43★ Vite 和 Webpack 的差别？

Webpack 先打整个依赖图再起服务，改一行要重建那块；Vite 开发时跑原生 ESM，按需编译，冷启动快，生产用 Rollup。迁移成本在 CommonJS 依赖和 require 动态写法上。腾达那套 Vue2 项目是 Webpack，迁不动也没必要迁。

44打包体积优化做过什么？

组件库按需引入、路由懒加载、图片压缩和小图 base64、开 gzip（vite-plugin-compression）、大库动态引入（ECharts、富文本）。再就是看构建分析找大包。不吹百分比，首屏 chunk 确实小了。

45ESLint 全量怎么推？有人不配合怎么办？

先接 pre-commit，lint-staged 只查暂存文件管住新代码；CI 上加一道全量；存量代码注释豁免排期清。阻力肯定有，我的办法是量化——统计低级错误在 review 里返工几次，数字摆出来，再找个模块试点跑通，再推全量。

46单元测试你写过什么？

工具函数和几个表单组件的测试，用 Jest + Vue Test Utils，覆盖校验规则和边界值。覆盖率不算高，属于关键逻辑有兜底。这个我照实说，不吹全量测试。

47Git 分支和发版怎么走的？

基本是 master + test 两条线，功能分支开发完合 test 提测，测过合 master 发版。冲突多的时候每天上班先拉一次。我早期提交信息写得随意（一堆 fix: u），后来自己看了都痛苦，这也是我后来比较在意提交规范的原因。

48多环境怎么配的？

.env.development、.env.production 这些文件，变量以 VITE_/VUE_APP_ 开头，构建时按 mode 注入；接口地址这类就放环境变量，别写死在代码里。部署脚本按环境传参。

49微前端了解吗？

知道原理：主应用注册子应用、加载子应用的资源、管理生命周期，qiankun 用沙箱隔离 JS 和样式。⚠ 我没有在生产里落地过，面试就说"了解思路，没实际做过"，别硬编经历。

50monorepo 了解吗？

pnpm workspace 那种，多个包放一个仓库共享依赖和配置。⚠ 我没搭过，只了解概念。前端面试问这个一般是团队有基建，照实说就行。

51code review 你看什么？

先看逻辑和边界（空值、异常、超时），再看有没有重复能抽，然后命名可读性，最后看埋坑（定时器、监听没清）。风格交给 ESLint，不在 review 里吵。

五、多端 / 小程序（52–58）

52★ uni-app 的原理？和原生小程序差别？

一套 Vue 代码，编译到小程序、H5、App。靠编译器把 Vue 模板转成各端的产物，加条件编译处理平台差异，运行时把小程序 API 映射成统一接口。小程序端最终产物还是 WXML/WXSS，逻辑层渲染层分离，不能直接操作 DOM。

53小程序性能，setData 有什么坑？

逻辑层和渲染层通信有成本，setData 数据越大越慢。所以：只传变化的部分、别整包传大对象、列表分页而不是一次全塞、频繁更新的字段合并着设。另外主包控制在 2MB 内，超了用分包。

54自定义导航栏怎么做？

页面 json 配 navigationStyle: "custom" 隐藏默认栏，组件里用 getWindowInfo 拿状态栏高度、getMenuButtonBoundingClientRect 拿胶囊位置，顶部 padding 撑开状态栏、右侧留出胶囊宽度，标题才不会被挡。

55H5 适配你都做过什么？

viewport、rem/vw、clamp()、安全区 env(safe-area-inset-bottom)、1px 处理、点击 300ms 延迟（现在基本没了）、横竖屏。移动端还要处理键盘弹起把布局顶上去的问题，监听 resize 调。

56小程序登录流程？

wx.login 拿 code 传给后端，后端用 code 换 openid 和 session_key，返回自定义 token，前端存起来带在请求头。code 只能用一次、有时效。涉及手机号要用户点授权拿加密数据，后端解密。

57原生小程序、uni-app、Taro 怎么选？

只发小程序、要极致性能就原生；多端复用选 uni-app（Vue 语法）或 Taro（React 语法），看团队栈。我们三个小程序里两个是 uni-app、一个是原生，都是按这个逻辑选的。

58多端一致性怎么保证？

业务逻辑抽到公共层（接口、状态、工具），视图各自实现；平台差异封成适配函数（存储、跳转、分享）；样式用统一变量，别在页面里写死平台判断。联调时列一张两端字段和流程对照表，能省很多来回。

六、项目追问（59–78）

6.1 一体化考试平台（创联）

59阅卷这块的业务流程怎么理？

先建阅卷计划（选考试、科目、时间窗、阅卷老师），分配后生成阅卷任务，老师按题目切块打分，专家入场签到，最后汇总成绩、审核。状态多，我先把状态图画出来，再对着接口字段一个个对。

60阅卷老师选择器为什么单独抽组件？

阅卷计划和阅卷任务都要选人，筛选条件还不完全一样。抽出来后传不同查询参数，内部统一处理分页、多选、已选回显，改一处几处生效；不抽就是复制一份再改，两边越改越不像。

61试卷水印怎么加的？防得住截图吗？

canvas 画文字（考生信息 + 时间）生成图片平铺在容器上，pointer-events: none 不挡操作，导出时一起带上。防不住专业截图，但能追溯到人，属于威慑加追溯。这点我跟产品说过。

62导出 PDF 的 <br> 问题怎么解决的？

富文本存的是 HTML，里面有 <br> 和一堆内联样式，直接丢给 PDF 生成器会换行乱、标签漏出来、样式丢。解决是导出前先洗内容：<br> 转段落、样式内联、去掉不支持的标签，再喂给生成器。类似坑还有图片跨域和中文字体。

63监考中心的列表难在哪？

列多、状态多，还要实时看考场情况。做法是列配置化（默认显示哪些、可切换）、固定关键列、状态字典映射颜色；先做静态页跑通交互再接接口，避免等后端。

64成绩里为什么有人脸识别记录？

防作弊的一环，成绩详情里能看到入场时的核验记录，列表里做了显隐控制。涉及隐私，接口那边也做了权限。

6.2 腾达（路由器管理 + 后台重构）

65一套代码出十几个国家的页面，怎么做的？

文案不写死在模板里，走固件注入的翻译函数，语言包按国家分目录，切换后刷新生效。坑是词条 key 命名乱、一个词多个译法，后来靠词条表统一，我还写了个 Node 脚本从 Excel 提词条生成 json。

66★ 前端做 AES 加密有意义吗？

有但有限。JS 里的密钥谁都能翻出来，它提高的是抓包和改包的成本，满足固件那边的协议要求，真正安全靠 HTTPS 和后端校验。而且我们那版 IV 是固定的，现在看不合规，正确做法是每次随机 IV 跟密文一起传——这是后来才想明白的。

67老系统重构怎么保证不出事？

不推倒重来。顺序：先把请求层收口（原来各页面各写 ajax），再拆路由理模块，然后统一组件和样式，最后动页面。每步都能单独上线、单独回滚。难的不是代码，是别人还在这个分支开发，得对齐节奏。

68mixin 后来为什么被淘汰？

隐式依赖太多，this.xxx 不知道从哪来；多个 mixin 同名会覆盖；改一个影响所有引用页面。组合式函数显式引入、来源清楚，Vue3 就用它替代了。

69路由器页面和普通后台有什么不一样？

跑在固件浏览器里，内核老、性能弱、兼容要求高。那套虽然用了 reasy-ui，但下面一堆兼容代码——global.js 直接往 HTMLElement.prototype 上加 addClass/removeClass，就是绕老浏览器的坑。所以那边写代码比后台克制。

70客户定制怎么做到不复制代码？

先看差异：小的（字段显隐、文案）用配置；中等的（多几步流程）用策略或状态机；大面积不一样才单独开分支。复制最省事也最贵，我尽量往配置上收，收不动的老实复制，但注释写清从哪份来的。

6.3 成都市育龄妇女平台（瀚维）

71配置化表格的边界在哪？

覆盖"查列表、弹表单、提交"这类占八成的页面就值了。复杂的（合并单元格、多行嵌套、特殊交互）留插槽或者干脆不封装。强行全覆盖最后等于自己写了个框架，没人会用。

72require.context 的原理和限制？

Webpack 编译时扫目录生成上下文函数，能拿 key 和模块。我用它自动注册 api、store、svg 图标，加文件不用改入口。限制是参数必须字面量，不能拼路径；Vite 里对应 import.meta.glob。

73表格高度自适应怎么算的？

页面不整页滚，表格内部滚、表头固定。高度 = 视口 − 搜索区 − 分页 − 边距，监听 resize 防抖重算。基层机构有 4:3 屏，最小高度也设了下限，不然只剩两行。

74一键部署脚本做了什么？

Node 脚本串起来：拉代码、装依赖、构建、打包、传服务器、解压替换、重启。任一步失败就中断并打印原因，目标环境和分支可传参。属于自己给自己省时间的工具。

6.4 职证宝小程序（uni-app）

75题型组件怎么拆的？

题目、答案解析、答题卡三个组件。题型差异在题目组件内部按类型分支渲染，答题卡单独维护作答状态，解析组件负责答案和解析。刷题、模拟、错题、收藏都复用，只是外面套的壳不同。

76答题卡和题目区双向联动怎么做？难点？

点答题卡跳题：算题目节点偏移滚过去；反向：监听滚动算出当前第几题，更新高亮。难点是小程序 setData 频繁会卡，高亮状态合并更新、滚动节流；吸顶元素高度要算进去，不然定位偏。

6.5 志愿者平台

77双端同期上线怎么排的？

先把接口和数据模型定下来，小程序和后台并行；小程序偏展示表单，后台偏管理审核。中间对齐两次，一次字段一次流程。坑是两边对同一个状态理解不一致，联调才发现，后来拉了状态对照表。

78权限组件和指令怎么选？

页面级用路由守卫，按钮级用指令或 Authority 组件。组件模板里看得见、能传 fallback；指令能控第三方组件里的按钮。两个都留，看场景用。

七、场景题（79–85）

79线上突然白屏，你怎么查？

先看影响面：所有用户还是部分、所有页面还是单个。然后看控制台报错和资源加载，常见是发版后 index.html 引的 JS 404（发布不完整/缓存）、接口结构变了渲染报错、CDN 挂了。先回滚止血，再定位，最后补监控和回归。

80首屏 3 秒要压到 1 秒，怎么做？

先测，Performance 看时间花在哪——下载、JS 执行还是接口慢。然后对症：拆包懒加载、图片压缩和 CDN、接口并行或服务端渲染、关键 CSS 内联、字体别阻塞。不承诺一定到 1 秒，看瓶颈在哪。

81后端接口没好，你怎么并行？

让后端先给接口文档，我按文档手写 mock（本地 mock 文件或拦截层），字段结构对齐，联调时一换就行。⚠ 别说"我写了个 mock 生成器"，说"手写 mock + 约定字段"更稳。

82接手老项目第一周干什么？

先跑起来，跑不起来先解决环境；再看目录和路由，画模块地图；然后看请求层和权限，这两块是入口；最后挑个最简单的需求改一遍，走完整个流程，比看一周代码有用。

83需求中途大改怎么处理？

先确认范围和原因，评估影响（改几个页面、多久、要不要动接口），成本摆给产品和上级，让他们决定这次改还是下版。做完的部分能复用就复用，不能就明确废弃。不闷头改，也不直接拒绝。

84线上事故复盘怎么写？

不写"某人粗心"，写机制：时间、现象、影响面、直接原因、根本原因、止血动作、后续动作和负责人。我见过的复盘里，最有效的往往是加一条自动化检查，而不是"下次注意"。

85从零搭一个后台，你怎么选型？

看团队：Vue 熟就 Vue3 + Vite + TS + Element Plus + Pinia；React 熟就 Ant Design。再看要不要权限、国际化、多端。不为新而新，能复用现成模板就复用，时间花业务上。
